
# Repositório base da atividade inicial da disciplina de psoft

## Atividade inicial 

1. Criar uma branche para o desenvolvimento da atividade 1 chamada psoft-atv1;

2. Desenvolver um CRUD (create, revorey, update and delete) pessoas no sistema com base nas informações de nome, idade,
cpf, telefone, endereço e profissão. Cada pessoa criada no sistema pode ter mais de um enderço cadastrado. Apenas o nome e 
cpf de uma pessoa não podem ser atualizados;

3. Modelar um diagrama de classes do sistema desenvolvido e adicionar ao repositório em formato pdf;

4. Criar um pull-request a partir da branche psoft-avt1 para a branche main (principal);

5. Responder o formulário do classroom com as informações sobre a atividade desenvolvida.
